# Справочник параметров для пользователей

В этом документе подробно описаны все параметры, которые вводятся пользователем при работе с двумя основными скриптами проекта:

- **train_model.py** — обучение страховой модели
- **real_calculator.py** — расчёт страховой премии

---

## 📘 real_calculator.py — Исследовательский калькулятор страховой премии

Этот скрипт используется для расчёта страховой премии на основе обученной модели.

### 1. Файл модели и DGP

| Параметр | Описание | По умолчанию | Пример |
|----------|----------|--------------|--------|
| **Путь к файлу модели** | Путь к файлу `model_params.json`, содержащему обученную модель | `model_params.json` | `models/model_v1.json` |
| **Путь к калибровке DGP** | Путь к файлу `calibrated_dgp.json` с параметрами генератора данных (можно оставить пустым для автоопределения) | `auto` | `calibration_output/calibrated_dgp.json` |

### 2. Пиковая нагрузка (PeakLoad)

| Параметр | Описание | По умолчанию | Пример |
|----------|----------|--------------|--------|
| **Пиковая нагрузка** | Значение пиковой нагрузки на оборудование. Можно выбрать квартили из данных обучения или ввести своё значение | Медиана (Q50) | `0.75` |

Доступные варианты:
- Нижняя квартиль (25%) — консервативный сценарий
- Медиана (50%) — средний сценарий
- Верхняя квартиль (75%) — агрессивный сценарий
- Все три значения — расчёт для всех сценариев
- Своё значение — ручной ввод

- Брутто-премию (с учётом нагрузки)
- Ожидаемую стоимость ремонта и простоя

## 🔑 Краткие пояснения ключевых понятий

### PeakLoad (Пиковая нагрузка)
Показывает, насколько сильно нагрузка на оборудование превышает средние значения. Чем выше PeakLoad, тем выше риск отказа.

### gamma (Эффект PeakLoad)
Показывает, насколько сильно пиковая нагрузка влияет на вероятность отказа. gamma=0 означает, что PeakLoad не влияет. gamma=1 означает умеренное влияние.

### delta (Гетерогенность)
Отражает разницу в рисках между разными тракторами. Чем выше delta, тем больше разброс в надёжности.

### Страховая нагрузка (theta)
Надбавка к чистой премии для покрытия административных расходов, резервов и прибыли.

### Горизонт прогнозирования
Период времени (в мото-часах), на который рассчитывается вероятность страхового случая.

### Калибровка
Процесс настройки модели так, чтобы её предсказания соответствовали реальной частоте отказов.
