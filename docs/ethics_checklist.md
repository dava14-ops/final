# Этический чек-лист сбора claims-данных

> **Версия**: 1.0
> **Дата**: 2026-08-15
> **Связанный документ**: `docs/data_contract.md`

## 1. Соответствие 152-ФЗ (персональные данные)

- [ ] Данные тракторов обезличены (machine_id — хэш, без ФИО/адресов).
- [ ] В датасете отсутствуют прямые идентификаторы физических лиц.
- [ ] Проведена оценка необходимости обработки персональных данных.
- [ ] Если обработка ПДн неизбежна — оформлено правовое основание.

## 2. Согласие и договоры

- [ ] Получено согласие на использование данных от каждого источника.
- [ ] Подписан договор о конфиденциальности с каждым источником.
- [ ] Определены цели использования данных (только актуарное моделирование).
- [ ] Определён срок хранения данных.

## 3. Безопасность данных

- [ ] Данные хранятся в зашифрованном виде (at-rest).
- [ ] Передача данных осуществляется по защищённым каналам (in-transit).
- [ ] Доступ ограничен авторизованными актуариями и ML-инженерами.
- [ ] Ведётся аудит-лог всех обращений к данным.

## 4. Обезличивание

- [ ] machine_id — необратимый хэш или псевдоним.
- [ ] Удалены или захэшированы GPS-координаты, позволяющие идентифицировать хозяйство.
- [ ] Удалены имена операторов, механиков, владельцев.
- [ ] Агрегированные данные не позволяют реидентификацию.

## 5. Использование данных

- [ ] Данные используются только для актуарного моделирования.
- [ ] Данные не передаются третьим лицам без согласия.
- [ ] Данные не используются для дискриминационного ценообразования.
- [ ] Модель не использует защищённые признаки (пол, возраст оператора, форма собственности).

## 6. Хранение и удаление

- [ ] Определён срок хранения данных.
- [ ] По истечении срока данные удаляются безвозвратно.
- [ ] Процедура удаления задокументирована.
