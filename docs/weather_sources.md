# Источники погодных данных для IV (Фаза 5.2)

## Приоритет 1: Росгидромет (основной для РФ)
- URL: https://meteo.ru / http://aisori.meteo.ru
- Что даёт: суточные осадки, температура по метеостанциям
- Доступ: открытые архивы частично; полные данные по запросу
- Покрытие: вся РФ, длительные ряды
- Формат: CSV/Excel после запроса
- Примечание: требует официального запроса для полных архивов

## Приоритет 2: NASA POWER (резерв, бесплатный API)
- URL: https://power.larc.nasa.gov/data-access-viewer/
- API: https://power.larc.nasa.gov/api/temporal/daily/point
- Что даёт: осадки (PRECTOTCORR), температура (T2M), сетка 0.5°
- Доступ: бесплатный, без регистрации
- Покрытие: глобальное, с 1981
- Формат: JSON/CSV через API
- Примечание: хорош для быстрого прототипа; точность ниже станционных

## Приоритет 3: ERA5 / Copernicus (реанализ)
- URL: https://cds.climate.copernicus.eu/
- Что даёт: реанализ, осадки, температура, почвенная влага
- Доступ: бесплатный, требуется регистрация
- Покрытие: глобальное, с 1940, сетка 0.25°
- Формат: NetCDF (нужен xarray)
- Примечание: самый полный, но требует обработки NetCDF

## Приоритет 4: NDVI (косвенный прокси)
- MODIS: https://modis.gsfc.nasa.gov/data/
- Sentinel: https://dataspace.copernicus.eu/
- Что даёт: индекс вегетации → прокси рабочих дней
- Доступ: бесплатный
- Примечание: косвенный метод; использовать как кросс-валидацию

## Рекомендация для Фазы 6
1. Начать с NASA POWER (быстрый прототип, не требует запросов).
2. Параллельно подать запрос в Росгидромет (официальные данные).
3. ERA5 — для кросс-валидации и расширения покрытия.
4. NDVI — для проверки правдоподобности рабочих дней.
