# Схема погодных данных для IV (Фаза 5.2)

## 1. Основная таблица: weather_windows.csv

| Колонка | Тип | Обязательная | Описание |
|---|---|---|---|
| region_code | str | Да | Код региона (из regions_mis Фазы 4.5) |
| year | int | Да | Год кампании |
| campaign | str | Да | "sowing" или "harvest" |
| working_days_window | float | Да | Число рабочих дней в окне кампании |
| total_window_days | float | Да | Общая длина окна (для нормировки) |
| source | str | Да | Источник данных (roshydromet / nasa_power / era5 / ndvi) |

## 2. Правило расчёта working_days_window

День считается «рабочим», если одновременно:
- осадки < 5 мм/сутки, И
- температура в диапазоне [5°C, 35°C], И
- нет предупреждений о заморозках/засухе/шторме.

working_days_window = Σ(рабочих дней в окне кампании)

## 3. Окна кампаний (для РФ, по умолчанию)

| Кампания | Начало | Конец | Типичная длина |
|---|---|---|---|
| sowing (посевная) | 15 апреля | 15 июня | ~60 дней |
| harvest (уборочная) | 15 июля | 30 сентября | ~75 дней |

Регионы могут сдвигать окна. При сборе данных фиксировать фактические окна.

## 5. Требования к покрытию (критерий Фазы 5.2)

- ≥ 5 регионов
- ≥ 3 лет
- Для каждого региона — данные за все годы (полное покрытие)

## 6. Формат файла

- CSV, разделитель запятая, кодировка UTF-8
- Первая строка — заголовки
- Десятичный разделитель — точка
- Путь по умолчанию: `data/processed/weather/weather_windows.csv`
